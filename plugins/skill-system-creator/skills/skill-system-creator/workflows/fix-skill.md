# Fix a skill

The user says "fix the skill", "add this rule", or "it keeps doing X".

1. **Get the real example.** Ask what came out wrong, or look at the result in this chat. "It sounds off" isn't enough. Find the line or the step.
2. **Find where it belongs.** Open the skill's files and find the step the problem comes from. Check whether a rule already covers it. If one does, sharpen that rule instead of adding a second.
3. **Write the change as a rule with its reason.** "IF the opening explains background first, THEN start with the reader's problem, because readers decide in the first line." Add the exception if there is one ("…except in a story, which opens inside the moment").
4. **Show the change before making it.** Show the exact lines you'll add or change, and the file. Make the edit only after the user says yes.
5. **Run it again.** Re-run the skill on the same input, or a new one, and show that the problem is gone and nothing else broke.

Keep the skill short. If a fix makes SKILL.md long, move the detail into a `references/` file and point to it.
